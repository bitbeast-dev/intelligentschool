# Additional Pages - Intelligent School

## Pages to Create

### 1. About Page (`/about`)
Create file: `app/about/page.tsx`

### 2. Features Page (`/features`)
Create file: `app/features/page.tsx`

### 3. Contact Page (`/contact`)
Create file: `app/contact/page.tsx`

## Color Scheme
- **Primary Color**: Indigo (#4F46E5 - indigo-600)
- **Secondary Color**: Slate (#64748B - slate-600)
- **Background**: White (#FFFFFF)
- **Text**: Slate-900 (#0F172A)

## Design Guidelines
- Clean, minimal design
- Only use Indigo and Slate colors
- White backgrounds
- Simple borders and shadows
- Professional typography

## Navigation
All pages should include:
- Fixed top navigation bar
- Logo with Intelligent School branding
- Links: Home, About, Features, Contact
- Consistent footer

## Instructions
Run these commands to create the directories:

```bash
# Windows
cd app
mkdir about features contact
cd about
type nul > page.tsx
cd ..\features
type nul > page.tsx
cd ..\contact
type nul > page.tsx
```

Then copy the page content from the homepage structure and modify for each page.
